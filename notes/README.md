# 📚 My Knowledge Base

Welcome to **KB Studio** — your personal, locally-running knowledge base!

## Getting Started

1. **Browse files** using the file tree on the left
2. **Create new notes** with the toolbar or `Ctrl+N`
3. **Save** with `Ctrl+S`
4. **Switch views**: Edit, Split, or Preview

## Features

- ✅ Markdown rendering with live preview
- ✅ VS Code-like file tree
- ✅ Works completely offline
- ✅ No installation required
- ✅ All files stored as plain `.md` files on your disk

> Everything runs in your browser. No data leaves your machine.
